# Phishing Detection & Awareness Report

## Overview
This repository contains a phishing detection and awareness report created for academic purposes.

## Contents
- Phishing Detection Report (PDF)
- Sample phishing email evidence
- Tool screenshots used for analysis

## Tools Used
- Email Header Analyzer
- SPF / DKIM / DMARC inspection tools

## Analysis Approach
Real phishing email examples were analyzed by examining email headers,
authentication results (SPF, DKIM, DMARC), sender behavior, and routing patterns.
Based on these indicators, risk classification was performed.
